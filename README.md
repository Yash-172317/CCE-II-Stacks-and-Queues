# CCE-II: Stack and Queue Implementation

## Objective

To implement Stack and Queue data structures and understand their basic operations using C++.

## Programs Included

### Stack

### Queue
1. Queue using Array
2. Queue using Linked List

## Instructions

1. Open the required C++ program.
2. Compile the program using a C++ compiler.
3. Run the program.
4. Enter the required input.
5. Observe the output.

## Usage

The programs are used to demonstrate the implementation and basic operations of Stack and Queue using Array and Linked List.
